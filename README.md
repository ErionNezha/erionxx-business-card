# MR ERIONXX — Kartvizitë 3D

Kartvizitë dixhitale interaktive 3D me animime GSAP: rrotullohet me lëvizjen e miut dhe hapet me klikim.

## Demo Live
Hape **`index.html`** në GitHub Pages — ose provo demo-n direkt: [`demo/`](demo/)

## Kodi Burim
Kodi i plotë shfaqet në panelin **"Kodi Burim"** në faqen kryesore:
- `demo/index.html` — struktura
- `demo/styles/main.css` — stilet 3D
- `demo/scripts/main.js` — animimet GSAP

## Teknologjitë
HTML5 · CSS3 (3D transforms) · JavaScript · GSAP 3.11
